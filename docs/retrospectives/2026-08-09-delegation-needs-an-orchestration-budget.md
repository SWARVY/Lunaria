# 경계가 명확한 위임에도 조율 예산이 없으면 오케스트레이션 비용이 이득을 잠식한다

## 무엇이 일어났나

한 장시간 작업에서 범위가 분리된 구현과 리뷰를 말단 워커에게 위임했다. 파일 소유권,
Git 권한, 결과 계약은 지켜졌고 11개 워커 중 10개가 작업을 완료했다. 모든 워커는 메인
대화 기록을 전달받지 않는 독립 컨텍스트로 시작했고, 메인 에이전트가 결과를 다시
검증했다.

안전성과 완료율은 높았지만 효율은 기대에 미치지 못했다.

- 워커 실행 시간 중앙값은 약 4분 44초였고 최장 작업은 약 11분 52초였다.
- 완료를 기다리거나 상태를 확인하는 호출이 95회 발생했다.
- 같은 워커에 대한 후속 지시 11회와 중단 4회가 발생했다.
- 작은 문서 수정과 재리뷰가 연속되면서 실제 구현 전에 약 21분이 사용됐다.
- 메인 에이전트와 워커가 검증 책임을 중복 수행해 테스트, 타입 검사, 빌드가 여러 번
  반복됐다.
- 하나의 메인 작업이 여러 구현 단계와 통합 주기를 계속 보유하면서 컨텍스트가 크게
  누적됐다.

위임은 메인 컨텍스트의 세부 구현 오염을 줄였지만, 이번 표본에서는 총 작업 시간과 raw
토큰 사용량을 줄였다고 보기 어려웠다.

## 왜 일어났나 (근본 원인)

### 안전성 게이트와 경제성 게이트가 분리되지 않았다

기존 규칙은 워커가 처리해도 안전한지를 자세히 판정하지만, 작업 패킷 작성, 대기,
재검증까지 포함한 위임 비용이 직접 처리보다 작은지를 실행 가능한 기준으로 제공하지
않았다. 그 결과 단일 문서 수정이나 좁은 재리뷰도 기술적으로 위임 가능하다는 이유로
워커에게 전달됐다.

### 리뷰 루프에 종료 조건이 없었다

구현자와 리뷰어의 역할은 분리했지만 리뷰 횟수, 재리뷰 조건, 경미한 지적을 누가
수정하는지 정하지 않았다. 작은 수정 뒤에도 새 리뷰가 이어졌고, 다음 구현 단계의 시작이
늦어졌다.

### 워커 수명과 목표 수명이 일치하지 않았다

같은 워커가 최초 목표를 완료한 뒤 다른 수정과 검증에도 재사용됐다. 후속 지시가 새로운
목표인지 기존 목표의 보정인지 구분하는 기준이 없어 워커 컨텍스트가 커지고 중단과 재개가
반복됐다.

### 단계별 검증 책임이 겹쳤다

워커의 좁은 검증, 메인 에이전트의 수용 검증, 통합 검증, 배포 직전 검증이 각각 필요했지만
어떤 명령을 어느 단계에서 한 번만 실행할지 정하지 않았다. 안전을 높이기 위한 반복이
중복 비용으로 전환됐다.

## 어떻게 해결했나

이번 회고에서는 안전 규칙을 약화하지 않고 비용이 발생한 전환 지점을 분리했다.

1. 작은 단일 단계 수정은 위임 후보에서 제외한다.
2. 한 구현 단계는 구현자 1명과 리뷰어 1명을 기본 예산으로 둔다.
3. 경미한 리뷰 지적은 메인 에이전트가 수정하고 직접 검증한다.
4. 같은 워커의 후속 지시는 동일 목표의 보정 1회로 제한한다.
5. 워커는 좁은 검증, 메인 에이전트는 수용 검증, 단계 경계에서는 전체 검증을 맡도록
   검증 책임을 구분한다.
6. 큰 통합 또는 PR 병합 뒤에는 결정 문서를 인계점으로 삼아 새 메인 작업을 제안한다.

운영 표본이 하나뿐이므로 위 항목을 초기 운영 규칙으로 반영하고, 다음 작업에서 수치
기준과 상한을 재검증한다.

## 다음에 어떻게 예방?

다음 오케스트레이션 작업에서는 아래 지표를 작업 종료 시 기록한다.

- 위임 수와 완료·취소 수
- 워커별 실행 시간과 전체 경과 시간
- 후속 지시, 중단, 재시도 수
- 좁은 검증과 전체 검증 실행 횟수
- 메인 작업의 턴 수
- raw 입력과 캐시되지 않은 입력을 구분한 토큰 사용량

초기 운영 기준은 다음과 같이 실험한다.

- 예상 5분 미만이면서 기계적인 단일 단계 수정은 메인 에이전트가 직접 처리한다.
- 리뷰어는 한 구현 단계에 한 번 사용하며 Important 또는 Critical 문제가 남을 때만
  재리뷰한다.
- 후속 지시가 목표나 파일 소유권을 바꾸면 기존 워커를 재사용하지 않는다.
- 전체 테스트, 타입 검사, 빌드는 단계 통합과 최종 통합에서 각각 한 번 실행한다.
- 3개 이상의 추가 작업에서 같은 비용 패턴이 반복되는지 확인한 뒤 현재 초기 운영
  규칙을 강화하거나 완화한다.
